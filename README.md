# SQL Pigeon Racing Club Database & Performance Analysis

A SQL database project managing **pigeon owners, registered pigeons, racing events, release points, and race performance** while analyzing racing results and identifying top-performing pigeons and owners.

## 🎯 Objectives

* Manage pigeon owners and registered pigeons
* Track racing events and release points
* Record pigeon race performance
* Analyze speed, rankings, and race results
* Identify top-performing pigeons and owners
* Demonstrate practical SQL database concepts

## 🔍 Key Analysis

* Average speed of pigeons across races
* Pigeons performing above the overall average speed
* Pigeons that have never finished first
* Top 3 champion pigeons by total wins
* Release point with the fastest average speed
* Owner with the best overall performance
* Pigeon rankings within individual races
* Best speed achieved by each pigeon over time

## 🛠️ SQL Concepts

**DDL • DML • CRUD • JOINs • Subqueries • GROUP BY • HAVING • CASE • Aggregate Functions • CTEs • Views • Window Functions • String Functions • Date Functions**
